# 와플노블 개발 기록

사용자가 자리를 비운 동안(2026-11-12 밤~) 이어서 진행한 고도화 기록이에요.
항목마다 **한 것 / 확인한 방법 / 직접 보실 곳**을 적어요.

진행 규칙

- 배포하지 않고, Vercel·Neon처럼 계정이 필요한 작업도 하지 않는다
- 기존 템플릿 저장 형식과 DB 스키마는 하위 호환되게만 바꾼다 (마이그레이션은 drizzle generate)
- 로컬 DB의 작품·회차는 지우지 않는다
- 항목마다 타입 검사·린트·테스트·빌드 → ego-lite로 실제 화면 확인 → 커밋·push
