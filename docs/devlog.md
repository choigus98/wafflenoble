### 2026-11-12 19:00 · 7. 새 템플릿: 커뮤니티 게시글

- 한 것
  - '＋ 템플릿' 메뉴에 **커뮤니티 게시글** (게시판 글 + 댓글)
    - 카드: 게시판 이름, 제목 옆 `[댓글 수]`, 글쓴이 · 시각 · 조회, 본문, 추천 수, 댓글 목록
    - 댓글은 카톡·채팅창처럼 **대본으로** 씀

      ```
      밥알: 와 이거 진짜임? [20:31]
      ㄴ 글쓴이: ㅇㅇ 방금 봄 [20:32]      ← 'ㄴ '은 답글, '글쓴이:'는 글쓴이 닉네임 + 글쓴이 표시
      감자도리: 레전드 ㅋㅋㅋ
      둘째 줄도 있음 [3분 전]              ← 이름 없이 쓰면 앞 댓글에 줄바꿈
      --- 삭제된 댓글입니다 ---            ← 회색 줄
      ```
