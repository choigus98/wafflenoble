### 2026-11-12 18:26 · 2. 예약 발행 (+ 회차 수가 틀리던 버그 수정)

- 한 것
  - 에디터에 **예약** 버튼: 공개할 시각을 고르면 그때 길드원에게 보인다 (기본값은 두 시간 뒤 정각)
    - 예약된 회차: 위쪽에 `예약 · 11월 13일 (금) 오후 8:00`, 버튼은 예약 변경 / 예약 취소 / 지금 발행
    - 공개 전까지는 임시저장처럼 자동저장. 화면을 열어 둔 채 예약 시각이 지나면 '발행됨'으로 바뀌고, 그 뒤부터는 수정 반영을 눌러야 보임
    - 템플릿 편집 중에는 예약도 막힘
  - 공개 규칙 하나로 통일 (`src/lib/queries/visibility.ts`): 발행 상태이면서 공개 시각이 지난 회차만 길드원에게 보임. 시각은 DB 시계(`now()`) 기준이라 서버·브라우저 시계가 달라도 같음
    - 작품 목록의 회차 수·최근 업데이트, 회차 목록, 이어 읽기, 이전/다음 화, 좋아요·조회 기록이 모두 이 규칙을 따름
  - 관리자 화면 표시: 회차 목록 `예약 · ○월 ○일 (요일) 오후 ○:○○ 공개 예정`, 관리자 홈 `발행 2 · 예약 1 / 전체 3화`, 미리보기 뱃지
  - '지금 발행'은 예약 시각 대신 지금 공개. 예전에 발행했던 회차를 다시 발행하면 원래 발행일 유지 (스키마 변경 없음)
- **같이 찾은 버그 (원래부터 있던 것)**: 관리자 홈·작품 목록의 회차 수가 틀렸다 (3화짜리가 '1화'로 보임)
  - 원인: drizzle은 조인 없는 쿼리에서 컬럼을 `"id"`처럼 테이블 이름 없이 쓴다. 하위 쿼리 `where novel_id = "id"`에서 `"id"`가 작품이 아니라 안쪽 회차 테이블 id로 읽혔다 (회차가 1개일 땐 우연히 맞아 보였음)
  - 수정: 하위 쿼리를 한 파일에 모으고 안쪽 테이블은 별칭, 바깥 테이블은 이름으로 가리키게 바꿈 + 만들어지는 SQL을 검사하는 테스트 추가 (`visibility.test.ts`)
- 확인
  - `pnpm test` 50개 통과, 타입 검사·린트·빌드 통과
  - ego-lite: 2화를 2분 뒤로 예약 → 길드원(로컬 테스트 쿠키로 curl)에게 목록·주소 모두 안 보임 → 예약 시각이 지나자 바로 보임, 열어 둔 에디터도 '발행됨'으로 바뀜
  - 예약 → 지금 발행(공개 시각이 지금으로), 예약 → 예약 취소(임시저장으로) 모두 확인. 2화는 원래대로 임시저장으로 돌려 둠
  - 관리자 홈 `발행 3 / 전체 3화`, 열람 홈 `3화 · 1분 전`으로 개수가 바로잡힌 것 확인

### 2026-11-12 18:30 · 3. 붙여넣기 정리

- 한 것: 서식 없는 글(메모장·한글·카톡 등)을 붙여 넣을 때의 규칙 (`src/lib/paste.ts`, 에디터 `clipboardTextParser`)
  - 원래는 ProseMirror가 빈 줄 여러 개를 하나로 뭉개서, 일부러 띄운 간격이 사라졌다
  - 원고 습관을 알아봄: 문단 사이 60% 이상에 빈 줄이 있으면 '빈 줄 = 문단 구분'으로 보고, 더 띄운 만큼만 빈 문단으로 남김. 아니면 빈 줄을 그대로 살림
  - `* * *` `***` `---` `===` `ㅡㅡㅡ` `◇◆◇` `☆☆☆`처럼 기호만 있는 줄은 장면 전환(✦ ✦ ✦)으로. `……` `...` 같은 말줄임 줄은 그대로
  - 줄 끝 공백·윈도 줄바꿈 정리, 줄 앞 전각 공백(들여쓰기)은 남김
  - 워드·웹에서 복사한 HTML은 원래대로 정제: 제목·목록은 문단으로, 글꼴·색·이미지·링크 주소는 빠지고 굵게·기울임은 남음
- 확인
  - `pnpm test` 74개 통과 (붙여넣기 규칙 24개 추가), 타입 검사·린트·빌드 통과
